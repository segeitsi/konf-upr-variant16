# Эмулятор оболочки — вариант 16

Этап 5: команды `touch` и `rmdir` для изменения VFS.
Сохранены окно терминала и команды предыдущих этапов.

## Запуск

Нужен Python 3.10+ с tkinter. Сборка и установка пакетов не требуются.
Из папки проекта:

```sh
python3 -B scripts/generate_vfs.py data
./run.sh --vfs data/nested.zip --startup scripts/stage5.txt
```

Прямой запуск: `python3 -B -m src`; на Windows: `py -B -m src`.

## Возможности и настройки

Параметры передаются при запуске в обычном терминале:
`--vfs PATH` — путь к ZIP, `--startup PATH` — скрипт UTF-8,
`--help` — справка. Оба пути необязательны; без ZIP VFS пустая.

Ввод по Enter или кнопке «Выполнить». Кавычки сохраняют пробелы в путях.
Скрипт показывает ввод и вывод и останавливается при первой ошибке.
После ошибки можно продолжить вручную.

| Команда | Действие |
| --- | --- |
| `ls [-a] [-l] [пути…]` | Список файлов; `-a` — скрытые, `-l` — подробности |
| `cd [путь]` | Смена каталога; без пути — корень |
| `tail [-n N] файлы…` | Последние N строк; по умолчанию 10 |
| `cal [год]` / `cal месяц год` | Календарь |
| `touch пути…` | Создать пустые файлы или обновить время существующих узлов |
| `rmdir каталоги…` | Удалить пустые каталоги |
| `exit` | Закрыть окно |

`ls -l` показывает тип и права, размер в байтах, время изменения и имя.
`ls -la` включает скрытые файлы. Права берутся из ZIP или назначаются
по умолчанию. Время видно с микросекундами: результат `touch` заметен сразу.

VFS хранится в памяти. Исходный ZIP не меняется.
`touch` сохраняет содержимое файла; родительский каталог должен существовать.
`rmdir` не удаляет корень, текущий каталог и непустые каталоги.

## Примеры для защиты

Введите в окне после загрузки `data/nested.zip`:

```text
ls -l /docs/lines.txt
touch /docs/lines.txt
ls -l /docs/lines.txt
touch "новый файл.txt"
ls -l "новый файл.txt"
tail "новый файл.txt"
ls -l /docs
rmdir /docs/empty
ls -l /docs
rmdir /docs
```

Время существующего файла изменится, его размер и содержимое сохранятся.
Новый файл появится с размером 0 байт, пустой каталог исчезнет.
Последняя команда выдаст ошибку: `/docs` не пуст.
После перезапуска с тем же ZIP изменения сбросятся.

## Проверки

```sh
python3 -B -m unittest discover -s tests -v
./scripts/demo_mutations.sh
```

Тесты проверяют команды, ошибки и неизменность ZIP без открытия GUI.
Сценарий показывает `touch` и `rmdir` в окне; закрывайте каждое для перехода дальше.

## Устройство проекта

- `src/commands.py`: `Shell.execute` и обработчики команд.
- `src/vfs.py`: загрузка ZIP, виртуальные пути, чтение и изменение узлов.
- `src/config.py`: `parse_config` — параметры запуска.
- `src/startup.py`: `run_startup` — выполнение скрипта.
- `src/gui.py`: `ShellWindow` — окно и история команд.
- `src/__main__.py`: точка входа; `run.sh`: скрипт запуска.

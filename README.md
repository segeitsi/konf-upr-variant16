# Этап 4. Команды оболочки

Конфигурационное управление, ПР № 1, вариант 16. Этапы 1–4 выполнены.
Python 3.10+ с tkinter. Сборка и сторонние пакеты не нужны.

## Запуск

Из папки проекта:

```sh
python3 -B scripts/generate_vfs.py data
python3 -B src/__main__.py --vfs data/nested.zip --startup scripts/stage4.txt
```

На этом Mac используйте `.venv/bin/python` или `/opt/homebrew/bin/python3`.
Для кнопки ▶ выберите Python с tkinter. Проверка: `python3 -m tkinter`.
Также можно запускать `./run.sh` (на Windows — `py -B -m src`).
`run.sh` считает относительные пути от папки проекта.

Параметры запуска: `--vfs PATH` — ZIP, `--startup PATH` — скрипт UTF-8,
`--help` — справка. Они вводятся в обычном терминале при запуске.
Оба пути необязательны. Без ZIP VFS пустая, её имя — `MyVFS`.
Настройки выводятся в окно; имя архива — в заголовок и приглашение.

## Команды в окне

| Команда | Действие |
| --- | --- |
| `ls [-a] [пути…]` | Список файлов; `-a` включает скрытые |
| `cd [путь]` | Смена каталога; без пути — корень |
| `tail [-n N] файлы…` | Последние N строк; по умолчанию 10 |
| `tail -n +N файл` | Строки начиная с N |
| `cal [год]` / `cal месяц год` | Текущий месяц, год или заданный месяц |
| `exit` | Закрыть окно |

Пример: `cd "Мои документы"`. Поддерживаются абсолютные и относительные
пути, `.` и `..`; `--` отделяет путь, начинающийся с дефиса, от флагов.
`tail` читает UTF-8; календарь выводится с английскими названиями месяцев.

ZIP читается целиком в память без распаковки. Данные файлов хранятся
в base64, исходный архив не меняется. Стартовый скрипт содержит команду
на каждой строке. Ввод и вывод видны в окне; первая ошибка останавливает
скрипт, после чего можно продолжить вручную.

В сценариях с несколькими окнами закрывайте каждое для перехода дальше.
ZIP генерируются локально, в Git их нет.

## Исходники

`src/commands.py`: `Shell.execute`, `ls`, `cd`, `tail`, `cal`.
`src/vfs.py`: загрузка ZIP, пути, список узлов и чтение текста.
`src/config.py`: параметры; `src/startup.py`: выполнение скрипта;
`src/gui.py`: интерфейс; `src/__main__.py`: точка входа.

# Эмулятор оболочки — этап 5

Конфигурационное управление, ПР № 1, вариант 16. Выполнены этапы 1–5.
Python 3.10+ с tkinter; сборка и сторонние пакеты не нужны.

## Запуск

Из папки проекта:

```sh
python3 -B scripts/generate_vfs.py data
python3 -B src/__main__.py --vfs data/nested.zip --startup scripts/success.txt
```

На этом Mac используйте `.venv/bin/python` или `/opt/homebrew/bin/python3`.
Для кнопки ▶ выберите Python с tkinter. Проверка: `python3 -m tkinter`.
Другой способ: `./run.sh`; на Windows: `py -B -m src`.
`run.sh` считает относительные пути от папки проекта.

Параметры запуска: `--vfs PATH` — ZIP, `--startup PATH` — скрипт UTF-8,
`--help` — справка. Вводятся в обычном терминале при запуске программы.
Оба пути необязательны. Без ZIP создаётся пустая VFS с именем `MyVFS`.
Настройки видны в окне; имя архива — в заголовке и приглашении.

## Команды в окне

| Команда | Действие |
| --- | --- |
| `ls [-a] [пути…]` | Список файлов; `-a` включает скрытые |
| `cd [путь]` | Смена каталога; без пути — корень |
| `tail [-n N] файлы…` | Последние N строк; по умолчанию 10 |
| `tail -n +N файл` | Строки начиная с N |
| `cal [год]` / `cal месяц год` | Текущий месяц, год или заданный месяц |
| `touch пути…` | Создать пустой файл или обновить время узла |
| `rmdir каталоги…` | Удалить пустые каталоги |
| `exit` | Закрыть окно |

Примеры: `cd "Мои документы"`, `touch "новый файл.txt"`,
`tail -n 3 /docs/lines.txt`, `cal 2 2024`, `rmdir /docs/empty`.
Поддерживаются `/`, относительные пути, `.` и `..`; `--` отделяет
имя с дефисом от флагов. `tail` читает UTF-8; названия месяцев английские.

ZIP читается в память без распаковки, содержимое файлов хранится в base64.
Изменения действуют до закрытия окна: исходный архив не меняется.
`touch` сохраняет содержимое существующего файла; родитель должен существовать.
`rmdir` запрещает удаление корня, текущего и непустого каталога.
Скрипт показывает ввод и вывод и останавливается при первой ошибке;
затем можно вводить команды вручную. При нескольких путях уже выполненные
операции сохраняются, оставшиеся после ошибки не выполняются.

## Проверка и защита

```sh
python3 -B -m unittest discover -s tests -v
PYTHON=/opt/homebrew/bin/python3 ./scripts/demo_success.sh
PYTHON=/opt/homebrew/bin/python3 ./scripts/demo_mutations.sh
```

`stage3.txt`, `stage4.txt`, `stage5.txt` — сценарии отдельных этапов.
`demo_vfs.sh` показывает три структуры ZIP; `demo_commands_errors.sh`
и `demo_vfs_errors.sh` — ошибки команд и загрузки. В сценариях с несколькими
окнами закрывайте каждое для перехода дальше. ZIP генерируются локально.

Исходники: `src/commands.py` — `Shell.execute` и команды; `src/vfs.py` —
`load`, `resolve`, `children`, `text`, `touch`, `rmdir`; `src/config.py` —
параметры; `src/startup.py` — скрипты; `src/gui.py` — окно.
Точка входа: `src/__main__.py`. Проверки: папка `tests`.

# Эмулятор оболочки — вариант 16

Этап 2: параметры запуска и выполнение стартового скрипта.
Сохранены графическое окно и разбор команд первого этапа.

## Запуск

Нужен Python 3.10+ с tkinter. Сборка и установка пакетов не требуются.
Из папки проекта:

```sh
./run.sh --vfs "data/Моя VFS.zip" --startup scripts/success.txt
```

Для запуска без скрипта: `./run.sh`.
Прямой запуск: `python3 -B -m src`; на Windows: `py -B -m src`.
Точка входа `src/__main__.py` также запускается как обычный Python-файл.

## Возможности и настройки

Параметры передаются при запуске в обычном терминале:
`--vfs PATH` — путь к VFS, `--startup PATH` — скрипт UTF-8,
`--help` — справка. Оба пути необязательны.

Настройки выводятся в терминал и окно. Имя VFS берётся из имени файла;
без пути используется `MyVFS`. На этом этапе ZIP ещё не читается,
поэтому указанный архив не обязан существовать.

Ввод по Enter или кнопке «Выполнить». Кавычки сохраняют пробелы в аргументах.

| Команда | Действие на этапе 2 |
| --- | --- |
| `ls [пути…]` | Выводит имя команды и список аргументов |
| `cd [путь]` | Выводит имя и аргументы; допускается один путь |
| `exit` | Закрывает окно; аргументы запрещены |

`ls` и `cd` пока работают как заглушки. Например, `cd "Мои документы"`
покажет аргумент `["Мои документы"]`, но не изменит каталог.

## Стартовый скрипт и примеры для защиты

Файл UTF-8 содержит одну команду на строку. Пустые строки пропускаются,
комментарии не поддерживаются. Скрипт выполняется при запуске;
окно показывает команды и результаты. Первая ошибка останавливает скрипт
с указанием файла и строки. После ошибки можно продолжить вручную.

| Сценарий | Что показать |
| --- | --- |
| `./scripts/demo_success.sh` | Параметры запуска, кавычки и вывод команд |
| `./scripts/demo_error.sh` | Остановку на первой ошибке |
| `./scripts/demo_missing.sh` | Ошибку чтения отсутствующего скрипта |
| `./scripts/demo_exit.sh` | Завершение через `exit` |

После ошибки введите `ls` в окне: ручной ввод должен работать.
В сценарии с `exit` команды после него не выполняются.

## Проверки

```sh
python3 -B -m unittest discover -s tests -v
```

Тесты проверяют разбор команд, параметры запуска, стартовые скрипты
и обработку ошибок без открытия GUI.

## Устройство проекта

- `src/config.py`: `parse_config` — параметры; `Config` — настройки и имя VFS.
- `src/shell.py`: `parse_command` — разбор; `execute_command` — обработка команд.
- `src/startup.py`: `run_startup` — выполнение скрипта до ошибки или `exit`.
- `src/gui.py`: `ShellWindow` — окно, история и ввод команд.
- `src/__main__.py`: точка входа; `run.sh`: скрипт запуска.

# Эмулятор оболочки, вариант 16

Практическая работа № 1. Готовы этапы 1 и 2: окно терминала,
разбор команд, настройки запуска и стартовый скрипт.

## Запуск

Python 3.10+ с tkinter. Сборка и установка пакетов не нужны.
Команды ниже выполняются из папки проекта.

```sh
./run.sh
```

Точка входа: `src/__main__.py`. Её можно запускать кнопкой ▶ в VS Code
или командой `python3 -B src/__main__.py`.
Выберите интерпретатор с tkinter; на этом Mac он находится
в `/opt/homebrew/bin/python3`:

```sh
PYTHON=/opt/homebrew/bin/python3 ./run.sh
```

## Параметры

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | Путь к ZIP с VFS |
| `--startup PATH` | Путь к стартовому скрипту |
| `--help` | Справка |

Оба пути необязательны. Настройки выводятся в терминал и окно.
Имя VFS берётся из имени файла; без пути используется `MyVFS`.
ZIP пока не загружается, поэтому файл не обязан существовать.

```sh
./run.sh --vfs "data/Моя VFS.zip" --startup scripts/success.txt
```

`run.sh` отсчитывает относительные пути от папки проекта,
прямой запуск Python от текущей рабочей директории.

## Команды

Ввод по Enter или кнопке «Выполнить». Кавычки сохраняют пробелы:
`cd "Мои документы"`. Ошибки показываются в истории окна.

| Команда | Действие |
| --- | --- |
| `ls [пути…]` | Заглушка: выводит имя и аргументы |
| `cd [путь]` | Заглушка: выводит имя и максимум один аргумент |
| `exit` | Закрывает окно, аргументы запрещены |

## Стартовый скрипт и защита

Файл UTF-8: одна команда на строку, пустые строки пропускаются,
комментарии не поддерживаются. Скрипт выполняется при запуске;
окно показывает команды и результаты. Первая ошибка останавливает
скрипт с указанием файла и строки. Ручной ввод остаётся доступен.
`exit` завершает приложение.

| Сценарий запуска | Проверка |
| --- | --- |
| `./scripts/demo_success.sh` | Параметры, кавычки и успешное выполнение |
| `./scripts/demo_error.sh` | Остановка на первой ошибке |
| `./scripts/demo_missing.sh` | Ошибка чтения отсутствующего файла |
| `./scripts/demo_exit.sh` | Завершение через `exit` |

Для выбора Python перед сценарием добавьте
`PYTHON=/opt/homebrew/bin/python3`.

## Исходники

| Файл | Основные функции |
| --- | --- |
| `src/__main__.py` | `main`: разбор параметров и запуск окна |
| `src/config.py` | `parse_config`: параметры; `Config`: имя VFS и вывод настроек |
| `src/gui.py` | `ShellWindow`: окно, история, ручной ввод и запуск скрипта |
| `src/shell.py` | `parse_command`: разбор; `execute_command`: выполнение команд |
| `src/startup.py` | `run_startup`: чтение и выполнение стартового скрипта |

# ПР №2 — этап 5. Визуализация

Конфигурационное управление, вариант 16.
Анализ зависимостей Python-пакетов: BFS, порядок загрузки, D2 и ASCII.
Выполнены этапы 1–5. Данные получаются напрямую из PyPI JSON API.

## Запуск

Нужен Python 3.10+. Только стандартная библиотека, сборка не нужна.
Из папки проекта:

```sh
./run.sh --package requests --version 2.32.3 --ascii-tree
```

Прямой запуск: `python3 -B src/__main__.py` с теми же параметрами.
На Windows: `py -B -m src`. Справка: `./run.sh --help`.

## Настройки

| Параметр | Назначение |
| --- | --- |
| `--package NAME` | Имя пакета, обязательно |
| `--version VERSION` | Версия корневого пакета, обязательно |
| `--repository URL/PATH` | URL PyPI JSON API или тестовый JSON |
| `--test` | Использовать локальный тестовый репозиторий |
| `--ascii-tree` | Дополнительно вывести ASCII-дерево на этапе 5 |
| `--stage N` | Выбрать этап 1–5; по умолчанию 5 |

Репозиторий по умолчанию — `https://pypi.org`.
Настройки передаются при запуске, отдельного окна ввода нет.

## Примеры для защиты

```sh
./run.sh --package requests --version 2.32.3 --ascii-tree
./run.sh --package flask --version 3.0.3
./run.sh --package rich --version 13.9.4 > graph.d2
./scripts/demo.sh
```

D2 выводится в терминал; перенаправление `> graph.d2` сохраняет текст.
`--ascii-tree` добавляет дерево: `[cycle]` — цикл,
`[already shown]` — уже раскрытая общая зависимость.
В `examples/` есть D2, ASCII и сравнения для трёх реальных пакетов.
Версии и рёбра совпали с pip; порядок независимых узлов различается.
У pip нет штатного D2/ASCII-вывода: сравнивались `pip inspect`,
отчёт и фактический порядок установки.
Подробности: [сравнение](examples/COMPARISON.md).

Для зависимостей выбирается последняя подходящая стабильная версия.
Конфликт уже выбранных версий выдаёт ошибку; полного перебора, как у pip, нет.
Прямые URL зависимостей и динамические метаданные не поддерживаются.

Предыдущие этапы доступны через `--stage 1`, `2`, `3`, `4`.
D2-текст можно открыть в D2 Playground; рендерер приложению не нужен.

## Проверка

```sh
python3 -B -m unittest discover -s tests -v
```

Тесты работают без сети. Примеры с PyPI требуют подключения к интернету.

## Исходники

`render.py`: D2 и ASCII; `order.py`: порядок; `graph.py`: BFS;
`repository.py`: PyPI; `test_repository.py`: тестовые графы;
`requirements.py`, `markers.py`, `versions.py`: условия и версии.
Точка входа — `src/__main__.py`. Исходники находятся в `src/`, тесты — в `tests/`.
